# DealCheck — a Black Friday deal finder

A static site of real Black Friday and Cyber Monday deals, found and checked on 2026-11-27: 43 deals across Amazon, Best Buy, Target and Walmart, each with its store link, sale price, usual price, check time, source and a verdict on whether it is really a deal. Search and filters by category, store and discount all work; runs entirely from static files with no network requests.
